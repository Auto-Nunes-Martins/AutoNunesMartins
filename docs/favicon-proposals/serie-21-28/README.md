# Série 21–28 — composição tipográfica revista

Esta é a série atual; 13–20 fica como estudo de fundos, 05–12 como composição anterior e 01–04 como direção não aceite. Nenhum ficheiro anterior foi removido.

09/10 usava larguras semelhantes para duas palavras de comprimentos diferentes, dando alturas e pesos aparentes diferentes. Aqui ambas têm uma altura comum; o desenho de cada palavra vem de recortes reais dos PNG originais. O corte de NUNES foi alargado à esquerda para preservar a margem do itálico e a extensão de alpha foi auditada. Não se inventou uma fonte nem se redesenharam letras; também não se afirma dispor do vetor original. SVG auto-contido incorpora raster. A composição e as medidas são novas.

Quatro estudos de centro, intervalo, alinhamento e margem, em fundos reais claros/escuros. PNG/ICO são montados em cada resolução com alturas de letras iguais e coordenadas inteiras; não são apenas miniaturas do PNG 256. O SVG pode ser rasterizado de forma ligeiramente diferente a 16/32 px. O nome completo mantém um limite físico de leitura a 16 px, visível na comparação nativa.

proveniencia.json regista origem, SHA-256, recortes, margens de alpha, geometria e paleta. PNG 16/32/48/64/128/180/256; ICO 16/32/48/64. Nenhuma proposta ativa, sem alteração de comportamento por tema, commit, push ou deploy.
